## Maintaining the Notices

```bash
python3 Tools/generate-third-party-notices.py
python3 Tools/generate-third-party-notices.py --check
```

The generator verifies the pinned upstream archive hash, preserves original license/comment text and checks known file-level notices. The build checks that the generated file is current. Packaging copies it from the built app so its contents match the executable being distributed.

When dependencies change, review licenses and build/link information again. This is a component inventory and notice-preservation workflow, not a legal opinion or a guarantee covering every redistribution scenario.

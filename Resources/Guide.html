非整数帧率与时间码

采用电影 NDF 工作流，不采用 29.97 DF 的时间码跳号规则。帧率使用精确有理数；23.976 是 24000/1001，29.97 是 30000/1001，59.94 是 60000/1001。不存在通过删除或重复图像使时长“凑整”的操作。

一段为 10 × 标称帧率 帧，每帧播放时长为分母 / 分子。因此 23.976 为 240 帧、29.97 为 300 帧、59.94 为 600 帧、239.76 为 2400 帧，各为 10.01 实秒。整数帧率的段长为准确 10 实秒。2-pop 的两个标称秒在 1000/1001 时基下为 2.002 实秒。这与按 NDF 时间码安排整十秒相一致。

每本 Head 的 FFOA 参考设在本号整点，Head 从该点前十个标称秒开始。第四本：HEAD 首帧 03:59:50:00；PICTURE START 03:59:52:00；FFOA 04:00:00:00。

按本次交付约定，第四本 Tail 首帧独立从 04:00:00:00 开始，不读取正片时长。这个独立时间码起点不等于正片实际结束时间码；将 Tail 接到正片之后时，以帧相邻关系保持 LFOA 同步位置。24 FPS 的 Tail 2-pop 索引 47，时间码为 04:00:01:23。

本号支持 1–23，使用小时位区分本号，避免跨 24 小时产生重复码。超过 100 FPS 时内部 FF 为三位数字；MOV 时间码轨的 frameQuanta 写入完整标称帧率，部分接收软件可能用半速时间码显示 HFR，应以逐帧 CSV 校对。自定义支持整数帧率及 1000/1001 家族。

命名与格式

影片名_R04_HEAD_24FPS_1998x1080_Rec709_Full.00345360.tif

帧号为 NDF 时间码的实际累计帧数，补齐至少八位，不从零重置。上例对应 24 FPS 的 03:59:50:00。每个批次按本号分组，TIFF10_COMPAT 文件夹存放 10-bit 有效精度兼容 TIFF；ProRes422HQ 文件夹区分 MOV 编码，避免破坏指定的基本命名模板。

影片名_R04_TAIL_23.976FPS_1998x1080_Rec709_Video.mov

  • TIFF10_COMPAT：BitsPerSample=16,16,16。两种范围均使用 round(q10×65535/1023)。Full 黑白为 0 / 65535；Legal（Video）黑白为 4100 / 60218。以 Full 读取并四舍五入到 10-bit 后为 64 / 940，不再使用导致白色读作 939 的左移写法。灰阶和抗锯齿保留中间值。
  • TIFF 可选 Full 0–1023 或 Video 64–940，Rec.709 ICC；Deflate 无损压缩或无压缩。
  • MOV：Apple ProRes 422 HQ，10-bit 4:2:2；浮点 RGB 通过 Rec.709 矩阵转换成原生 10-bit v210，再交给系统编码器，不经过 8-bit 中间图像。YCbCr 为 Video 范围，文件名因此写 Video；与 Full RGB TIFF 的范围标记不同，不是把 Video 冒充 Full。
  • Resolve 21.1 的 ProRes Full 解码实测会把原始 940 归一化成约 939.096。MOV 批次附带 Resolve_Full_Readback，含专用 DCTL 和使用限制，用于该读取路径恢复 64/940；原始 MOV 不写成非标准的 941。此校正不自动写入视频，不能用于 TIFF、Video/Auto 或其他已正确读取的路径。
  • MOV 写入真实 tmcd 时间码轨并与视频关联，视频采样时间戳使用精确分子 / 分母。TIFF 本身不保证在所有 NLE 中携带时间码或帧率，文件编号、ImageDescription、CSV 和 manifest 同时记录。
  • 可选 48 kHz / 24-bit PCM 单声道同步音轨与 WAV，2-pop 的一帧内为 1 kHz、-20 dBFS 峰值正弦波，其他时间静音。音频采样边界按有理数就近取整。

1.1.2 的 packed 10-bit TIFF 可被 LibTIFF 解码，但 macOS ImageIO / Quick Look 无法可靠读取，因此 1.1.3 统一改用上述兼容容器。PNG 只供视觉检查。DCI 2K / 4K 是尺寸预设，不代表 XYZ、DCDM、HDR 或 DCI 色彩认证。

依据与适配边界

本版是按需求组合的十秒数字适配，不是完整物理胶片标准认证复刻。参考资料：

  • EBU Tech 3203 (1973)：Frame 172 / 170 / 164 分别是 16 COMMAG / 16 COMOPT / 35 COMOPT 的单帧声画同步指示，Frame 144 是所有声轨的 START 参考。为了让数字工作流更易理解，本版仅把该帧的显示文字改为 SOUND START，时间位置不变。其原始 240–193 帧是 10 / 9 倒计时，本版按需求改为信息段。
  • SMPTE ST 55:2011：电视胶片 Leader 的秒数倒计时与接片规则。
  • SMPTE ST 301:2005：影院胶片 Leader，采用 16 格单位而不是本版秒数双时钟。
  • Apple TN2310：QuickTime 时间码轨与视频关联、时间码格式描述。

COMMAG / COMOPT 是不同胶片制式的声重放头位置指示：16 COMMAG 为 16 mm 磁性声带，16 COMOPT 为 16 mm 光学声轨，35 COMOPT 为 35 mm 光学声轨；其帧位按各声头到片门相对于 Frame 144 START 的机械距离安排。因此本版保留三个原始相对帧位，并让每项只出现一帧。数字 HFR 映射仅保留时间比例，不宣称复制实际胶片机械距离。音频 2-pop 固定在两秒。本版不生成光学声轨、保护胶片、换机点或四格占位色卡。

安装与构建

Apple Silicon，构建目标 macOS 13 及以上；未在所有系统版本和 NLE 中验收。应用使用 ad-hoc 签名，未获 Apple Developer ID 签名或公证。不要关闭系统安全保护。源码、构建脚本、LibTIFF 源码归档和测试脚本位于 Develop/LeaderTools，执行 bash build.sh 重建。

无网络功能、无 Python 或 FFmpeg 运行依赖。系统 AVFoundation 编码 MOV，LibTIFF 静态链接。批次使用唯一目录，失败 / 取消保留 .partial 与状态。磁盘空间不足时停止并保留已完成文件。

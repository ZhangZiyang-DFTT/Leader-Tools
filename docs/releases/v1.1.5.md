# Leader Tools 1.1.5

Native macOS film head/tail leader generator, developed by ZhangZiyang-DFTT in collaboration with OpenAI Codex.

## 下载与运行

- 下载附件 `Leader_Tools_1.1.5.dmg`，打开后将应用拖入 Applications。
- Apple Silicon Mac；macOS 13 及以上构建目标。不支持 Intel Mac。
- 应用运行无需 Python、FFmpeg、Homebrew 或网络。
- **当前为 ad-hoc 签名，未进行 Apple Developer ID 签名或公证**，macOS 可能提示无法验证开发者。
- `Source code` 是 GitHub 自动生成的源码归档，不是安装包。

## 功能

- 十个标称秒的 Head / Tail Leader，独立片名、本号、备注和可选 Logo。
- 多本批量生成、双时钟、声画同步标记、2-pop、边界三角及本号 NDF 时间码。
- 主流整数与非整数帧率，最高 240 FPS；FHD、UHD、DCI 2K / 4K 画幅。
- 10-bit 有效精度 TIFF 序列（16-bit RGB 容器）和 ProRes 422 HQ MOV。

## 1.1.5 码值修复与限制

- Legal TIFF 使用 `round(q10 * 65535 / 1023)`，黑白存储值为 4100 / 60218。以 Full 读取时，10-bit 浮点读数约为 64.0009 / 940.0017，四舍五入恢复 64 / 940。
- MOV 原始 ProRes Y 保持标准 Legal 64 / 940，不将源白色抬高到 941。
- 实测 Resolve 21.1.0.14 的 ProRes Full 解码路径会把源白 940 读作约 939.096。附带的 DCTL 可在该特定读取路径中恢复 64.0 / 940.0，**需要在接收端手动应用**。
- DCTL 不得用于 TIFF、Auto/Video 读取、已正确归一化的解码器或重复应用。使用前请阅读 `Resolve_Full_Readme.txt`；普通 DaVinci YRGB / Rec.709 的验收结果不代表所有 RCM/ACES 管线。
- 这是一套参考 EBU 标记的数字 Leader 适配工具，不是完整物理胶片 Leader 的 EBU/SMPTE 认证声明。
